Link checker results

This page simulates a CMS link checker handing its flagged links to the library through the brokenLinks option. Append ?noOk to the URL to test the button set shown to users who may not mark things OK, ?noMark to withhold link marks through allowLinkMarks while the page still allows OK, or ?deferChecks to keep unverifiable links behind the visualizers through brokenLinksShowChecks.
